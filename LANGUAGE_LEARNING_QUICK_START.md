# Language Learning System - Quick Start Guide

## 🚀 Getting Started

### 1. **First Time Setup**
- Navigate to `/language-learning`
- Select your target language (Chinese, Spanish, German, French, Hindi, or Bangla)
- Choose your learning ratio (70% Learning / 30% Practice is recommended for beginners)
- System generates a personalized roadmap with 77 lessons

### 2. **Dashboard Overview**
The dashboard shows:
- **Stats**: Total XP, Day Streak, Current Level, Lessons Completed
- **In Progress**: Lessons you've started but not finished (click to resume)
- **Completed Lessons**: All finished lessons with scores
- **Recent XP**: Last 10 XP events with reasons
- **Action Buttons**: Learn, Practice, Continue

### 3. **Learning Path**
```
Dashboard → Learn → Select Module → Complete 5-Step Lesson → Mastery Check
```

### 4. **Practice Path**
```
Dashboard → Practice → Select Practice Type → Complete Exercises → Get Score
```

## 📚 Lesson Structure (5 Steps)

Each lesson follows this flow:

1. **Introduction** (📖)
   - Overview of what you'll learn
   - Encouragement and context

2. **Core Content** (📚)
   - Main teaching material
   - Examples with translations and pronunciation guides
   - Explanations in your native language

3. **Mini Practice** (✏️)
   - Quick checks to reinforce learning
   - For voice modules: speaking practice with recording

4. **Summary** (📝)
   - Recap of key points
   - Reinforcement of concepts

5. **Mastery Check** (🎯)
   - 3 questions to verify understanding
   - Must score 80%+ (2/3 correct) to pass
   - For voice modules: record 3 phrases and score 80%+ on 2/3

**Navigation**: Click the numbered buttons (1-5) to jump between steps

## 🎯 Practice Types (9 Modes)

### 1. **Multiple Choice (📝)**
- 5 questions per session
- Select the correct answer
- Get instant feedback with explanations

### 2. **Flashcards (🃏)**
- Spaced repetition system
- Rate each card: Forgot / Hard / Easy
- Cards reappear based on your rating

### 3. **Typing (⌨️)**
- Type the target language word
- Get instant feedback on correctness
- Pronunciation hints provided

### 4. **Fill-in-Blank (✏️)**
- Complete sentences with missing words
- Multiple choice options
- Learn in context

### 5. **Speaking (🎤)**
- Record yourself speaking
- AI evaluates pronunciation
- Get score, feedback, and tips
- Speaker button to hear correct pronunciation

### 6. **Writing (📝)**
- Write on paper and take a photo
- AI reads your handwriting
- Get feedback on grammar, vocabulary, structure
- Bilingual feedback (target language + English)

### 7. **Listening (🎧)**
- Listen to audio passage
- See difficult words with pronunciation
- Answer comprehension questions
- Click 🔊 to replay audio

### 8. **Reading (📖)**
- Read a passage in target language
- Answer comprehension questions
- Learn vocabulary in context

### 9. **Conversation (💬)**
- Chat with AI in target language
- AI adapts to your level
- Get feedback on errors and improvements

## 📊 Stage Progression

The system has **7 stages** with **11 modules each**:

1. **Beginner** (11 modules)
   - Pronunciation guides for every word
   - Simple sentences (max 6 words)
   - English translations for all vocabulary

2. **Elementary** (11 modules)
   - Pronunciation for new words only
   - Slightly longer sentences (max 8 words)
   - Mix of target language and English

3. **Intermediate** (11 modules)
   - Minimal pronunciation guides
   - Complex sentences
   - Mostly target language

4. **Upper-Intermediate** (11 modules)
   - No pronunciation guides
   - Advanced vocabulary
   - Mostly target language

5. **Advanced** (11 modules)
   - Professional vocabulary
   - Complex grammar
   - Full target language immersion

6. **Mastery** (11 modules)
   - Native-level content
   - Specialized topics
   - Complete immersion

7. **Native** (11 modules)
   - Native speaker content
   - Cultural nuances
   - Full fluency

**Progression Rule**: You must complete ALL 11 modules in your current stage before unlocking the next stage.

## 💡 Tips for Success

### 1. **Consistency**
- Practice daily for best results
- Even 15 minutes per day is better than sporadic long sessions

### 2. **Complete Lessons First**
- Finish all lessons in a module before practicing
- Lessons teach concepts; practice reinforces them

### 3. **Use All Practice Types**
- Different practice types strengthen different skills
- Speaking practice improves pronunciation
- Writing practice improves grammar

### 4. **Review Completed Lessons**
- Click the numbered buttons to review previous steps
- Reinforcement helps long-term retention

### 5. **Pay Attention to Pronunciation**
- For beginner levels, pronunciation guides are provided
- Use the 🔊 speaker button to hear correct pronunciation
- Record yourself and compare

### 6. **Don't Rush**
- Take time to understand concepts
- Retake lessons if you score below 80%
- Quality over speed

### 7. **Use Flashcards**
- Flashcards use spaced repetition
- Review cards marked as "Hard" more frequently
- "Easy" cards reappear less often

## 🎓 Learning Principles

The system uses proven language learning principles:

1. **Comprehensible Input (i+1)**
   - 70% known content + 30% new content
   - Never overwhelming, always building on what you know

2. **Spaced Repetition**
   - Flashcards reappear at optimal intervals
   - Reinforces long-term retention

3. **Active Production**
   - Speaking and writing practice
   - Not just passive listening/reading

4. **Contextual Learning**
   - Words taught in sentences, not isolation
   - Real-world usage examples

5. **Immediate Feedback**
   - AI evaluates your responses
   - Corrections and tips provided instantly

6. **Adaptive Difficulty**
   - Content adjusts to your level
   - Pronunciation guides for beginners only
   - Complexity increases with each stage
