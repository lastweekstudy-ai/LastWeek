## 📚 Study Modes Documented

All 5 study modes fully documented:

1. **Mental Model Mode**
   - Purpose: Build conceptual understanding
   - Features: Concept mapping, visual learning
   - Best for: Learning new subjects

2. **Active Recall Mode**
   - Purpose: Test memory
   - Features: Quizzes, flashcards
   - Best for: Exam preparation

3. **Spaced Repetition Mode**
   - Purpose: Optimize retention
   - Features: Intelligent scheduling
   - Best for: Long-term learning

4. **Exam Prep Mode**
   - Purpose: Focused preparation
   - Features: Study schedules, mock exams
   - Best for: Exam preparation

5. **Focus Breakdown Mode**
   - Purpose: Deep dive learning
   - Features: Comprehensive analysis
   - Best for: Mastering difficult topics
