# LastWeek Logos

This folder contains the official LastWeek brand logos.

## Logo Files

### 1. `lastweek_main_logo.png`
- **Usage**: Primary logo with icon and text
- **Where used**: 
  - Landing page hero section
  - Auth/Login page
  - Marketing materials
  - Social media
- **Recommended size**: 120px height for web, scalable for print

### 2. `lastweek_text_logo.png`
- **Usage**: Text-only logo (horizontal)
- **Where used**:
  - Navigation bar
  - Email signatures
  - Compact spaces
- **Recommended size**: 48px height in navbar (increased for better visibility)

### 3. `lastweek_main_logo.ico`
- **Usage**: Icon/favicon version
- **Where used**:
  - Browser tab favicon
  - App icon
  - Social media profile picture
  - Bookmark icon
- **Format**: ICO file (image/x-icon)
- **Recommended size**: 16x16, 32x32, 64x64 pixels (multi-size ICO file)

## Usage Guidelines

### Do's ✅
- Use logos on solid backgrounds with good contrast
- Maintain aspect ratio when scaling
- Ensure minimum clear space around logo (equal to logo height)
- Use high-resolution versions for print

### Don'ts ❌
- Don't stretch or distort logos
- Don't change logo colors without approval
- Don't add effects (shadows, gradients, etc.)
- Don't place on busy backgrounds that reduce readability

## File Locations in Code

```javascript
// Landing page
<img src="/logos/lastweek_main_logo.png" alt="LastWeek Logo" />

// Navbar
<img src="/logos/lastweek_text_logo.png" alt="LastWeek" />

// Favicon (index.html)
<link rel="icon" type="image/x-icon" href="/logos/lastweek_main_logo.ico" />
```
