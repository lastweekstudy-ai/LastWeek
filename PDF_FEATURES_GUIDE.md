# PDF Features Guide - LastWeek

## Complete Guide to PDF Study Features

### 📄 Uploading PDFs

#### Supported Files
- **PDF Documents**: Up to 100MB
- **Scanned PDFs**: Automatic OCR text extraction
- **Image PDFs**: Vision AI extracts text from images
- **Multi-Page**: Unlimited pages supported
- **Encrypted PDFs**: Password-protected files supported

#### Upload Methods
1. **Drag & Drop**: Drag PDF into chat or resource area
2. **File Picker**: Click 📎 attachment button
3. **Paste**: Copy-paste PDF file
4. **URL Import**: Paste PDF URL (if supported)

#### Processing
- ✅ Automatic text extraction
- ✅ Page thumbnail generation
- ✅ Metadata extraction (title, author, pages)
- ✅ Full-text indexing for search
- ✅ Progress tracking setup

### 🖍️ Highlighting System

#### Creating Highlights

**Desktop**:
1. Click highlight button (🖍️) in toolbar
2. Drag mouse over text to select
3. Release to create highlight
4. Highlight saves automatically

**Mobile/Tablet**:
1. Tap highlight button (🖍️) in toolbar
2. Drag finger over text to select
3. Lift finger to create highlight
4. Highlight saves automatically

**Visual Feedback**:
- Yellow selection rectangle appears as you drag
- Highlight appears immediately after release
- Color indicator shows current highlight color

#### Highlight Colors

Choose from 6 colors for different purposes:

- 🟡 **Yellow** (Default)
  - General highlighting
  - Important information
  - Key concepts

- 🟢 **Green**
  - Definitions
  - Terminology
  - Foundational concepts

- 🔵 **Blue**
  - Examples
  - Case studies
  - Applications

- 🔴 **Pink**
  - Critical information
  - Exam-relevant content
  - Must-remember facts

- 🟠 **Orange**
  - Questions
  - Areas to review
  - Unclear concepts

- 🟣 **Purple**
  - Personal insights
  - Connections to other topics
  - Advanced concepts

#### Changing Colors

1. Click color palette button (🎨) in toolbar
2. Select desired color from picker
3. New highlights use selected color
4. Existing highlights keep their color

#### Managing Highlights

**View All Highlights**:
- **Desktop**: Check sidebar on right
- **Mobile**: Tap 📑 button in toolbar

**Navigate to Highlight**:
- Click/tap any highlight in list
- PDF jumps to that page
- Highlight is visible on page

**Remove Highlight**:
- Click ✕ button next to highlight in list
- Or right-click highlight on page → Delete

**Search Highlights**:
- Use search bar in sidebar
- Filter by color
- Sort by page number or date

### 📱 Mobile Sidebar

#### Opening Sidebar

**Toolbar Button**:
- Look for 📑 button in PDF toolbar
- Shows count: `📑 5` (5 bookmarks + highlights)
- Tap to open sidebar

**What Opens**:
- Bottom sheet slides up from bottom
- Takes 60% of screen height
- Backdrop dims background
- Handle bar at top for visual affordance

#### Using Sidebar

**Scrolling**:
- Swipe up/down to scroll through items
- Smooth scrolling with momentum
- Works with one finger

**Navigation**:
- Tap any bookmark to jump to that page
- Tap any highlight to jump to that page
- Sidebar auto-closes after navigation

**Closing**:
- Tap ✕ button in top-right
- Tap backdrop (dimmed area)
- Swipe down on handle bar
- Automatically closes after navigation

#### Sidebar Contents

**Bookmarks Section**:
- Shows all bookmarked pages
- Page number displayed
- Tap to navigate

**Highlights Section**:
- Shows all highlights with preview
- Color indicator for each
- Page number displayed
- First 45 characters of text
- Tap to navigate

**Empty State**:
- Shows helpful message when empty
- Suggests using toolbar to add items

### 🔖 Bookmarks

#### Creating Bookmarks

1. Navigate to page you want to bookmark
2. Click/tap star button (⭐) in toolbar
3. Star fills in to show bookmarked
4. Bookmark saved automatically

#### Removing Bookmarks

1. Navigate to bookmarked page
2. Click/tap filled star (⭐) in toolbar
3. Star empties to show removed
4. Or remove from sidebar list

#### Bookmark Uses

- **Important Pages**: Mark key chapters
- **Formulas**: Quick access to equations
- **Diagrams**: Find visual aids fast
- **Summaries**: Jump to review sections
- **Exam Topics**: Mark test-relevant pages

### 📝 Notes

#### Adding Notes

1. Click/tap notes button (📝) in toolbar
2. Note editor opens
3. Type your note
4. Click Save
5. Note attached to current page

#### Note Features

- **Rich Text**: Bold, italic, lists
- **Markdown**: Use markdown syntax
- **Timestamps**: Auto-added creation time
- **Page Link**: Linked to specific page
- **Private**: Only you can see your notes

#### Viewing Notes

- **Sidebar**: Shows notes for current page
- **Note Icon**: Indicator on pages with notes
- **Search**: Find notes by content
- **Export**: Download all notes

### 🔍 Search

#### Searching PDFs

**Within Current PDF**:
1. Click search icon (🔍) in toolbar
2. Type search term
3. Results highlight on page
4. Use arrows to navigate results

**Across All PDFs**:
1. Go to Resources library
2. Use main search bar
3. Results show matching PDFs
4. Click to open at matching page

#### Search Features

- **Full-Text**: Searches all text
- **Highlights**: Search your highlights
- **Notes**: Search your notes
- **Case-Insensitive**: Finds all matches
- **Instant Results**: Real-time search

### 🔧 Troubleshooting

#### Highlights Not Appearing

**Check**:
- ✅ Highlight mode enabled (🖍️ button active)
- ✅ Dragged over text (not blank space)
- ✅ Internet connection active
- ✅ Browser allows storage

**Fix**:
- Refresh page
- Re-enable highlight mode
- Check browser console for errors
- Try different browser

#### Sidebar Not Opening

**Check**:
- ✅ Have bookmarks or highlights
- ✅ Tapped correct button (📑)
- ✅ Not in desktop mode on mobile

**Fix**:
- Create a bookmark first
- Check toolbar for button
- Refresh page

#### Touch Highlighting Not Working

**Check**:
- ✅ Highlight mode enabled
- ✅ Using single finger (not multi-touch)
- ✅ Dragging over text
- ✅ Browser supports touch events

**Fix**:
- Disable pinch-zoom first
- Try different area of text
- Update browser
- Try different device

#### PDF Not Loading

**Check**:
- ✅ File size under 100MB
- ✅ Valid PDF format
- ✅ Internet connection
- ✅ Storage quota available

**Fix**:
- Try smaller file
- Re-upload PDF
- Clear browser cache
- Check Appwrite status

### 🎓 Study Techniques

#### SQ3R Method

1. **Survey**: Skim PDF, bookmark sections
2. **Question**: Note questions in margins
3. **Read**: Highlight key concepts
4. **Recite**: Summarize in notes
5. **Review**: Check highlights regularly

#### Cornell Notes

1. **Notes Column**: Main notes
2. **Cues Column**: Highlight key terms
3. **Summary**: Add page notes
4. **Review**: Use bookmarks

#### Feynman Technique

1. **Read**: Highlight concepts
2. **Explain**: Write notes in simple terms
3. **Identify Gaps**: Mark with orange
4. **Simplify**: Refine notes
5. **Review**: Check understanding
