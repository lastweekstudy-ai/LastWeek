## 📚 Main Sections

### 1. **Core Philosophy**
- The **i+1 Principle** (70% known + 30% new)
- Learning by doing, not memorizing
- Frequency-based teaching (most common words first)

### 2. **7 Learning Stages**
- **Beginner** → Elementary → Intermediate → Upper-Intermediate → Advanced → Mastery → Native-Like
- Each stage builds on the previous one
- Clear progression from survival to fluency

### 3. **11 Modules Per Stage**
- Vocabulary, Pronunciation, Speaking, Listening, Reading, Writing
- Grammar, Sentence Structure, Synonyms & Antonyms
- Idioms & Expressions, Cultural Context

### 4. **Teaching Principles**
- Comprehensible input first
- Context-based learning (words in sentences, not isolation)
- Pattern recognition over rules
- Active practice (speaking, writing, listening, reading)
- Spaced repetition
- Immediate feedback
- Motivation through progress
- Cultural sensitivity

### 5. **Student Profile System**
- Tracks: Native language, target language, current stage, completed modules
- Adapts teaching based on proficiency level
- Determines vocabulary, grammar complexity, and practice types

### 6. **5-Step Lesson Format**
1. **Introduction** - Set context and motivation
2. **Core Content** - Teach the main concept
3. **Examples** - Show real-world usage (5 examples)
4. **Mini Practice** - Quick exercises with feedback
5. **Mastery Check** - Verify learning (3 questions, 80% to pass)

### 7. **9 Practice Types**
- Vocabulary, Pronunciation, Speaking, Listening, Reading
- Writing, Grammar, Typing, Conversation

### 8. **Mastery Check System**
- 3 questions per lesson
- 80% passing score (2 out of 3 correct)
- Immediate feedback and rewards
- Can retry if failed

### 9. **7 Supported Languages**
- Spanish, Chinese, German, French, Hindi, Bengali, English
- Each with cultural context and unique features

### 10. **Adaptive Learning**
- Adjusts difficulty based on performance
- Adjusts pace based on learning speed
- Adjusts content based on weak/strong areas
- Adjusts to learning style (visual, auditory, kinesthetic)
- Adjusts motivation through rewards and challenges

## 🎯 Key Teaching Principles

| Principle | What It Means | Example |
|-----------|--------------|---------|
| **i+1** | 70% known + 30% new | Learn 3 new words in context of 7 known words |
| **Context First** | Words in sentences, not isolation | "Hola" in "Hola, ¿cómo estás?" not just "Hola" |
| **Pattern Recognition** | Show examples, then explain rules | 5 examples of past tense, then explain the rule |
| **Active Practice** | Students must produce language | Speaking, writing, not just reading |
| **Immediate Feedback** | Corrections right away | "Great! But try 'estoy' instead of 'soy'" |
| **Spaced Repetition** | Review at increasing intervals | Day 1, Day 3, Week 1, Month 1 |
| **Motivation** | Points, achievements, progress | Earn 25 XP per lesson, unlock next stage |
| **Cultural Awareness** | Respect target language culture | Learn about Spanish customs, not just words |

## 📊 Learning Progression

```
Stage 1: Beginner
├─ 100-200 words
├─ Present tense only
├─ Full romanization + translations
└─ Goal: Survive in basic situations

Stage 2: Elementary
├─ 300-500 words
├─ Past tense added
├─ Romanization for new words only
└─ Goal: Handle everyday conversations

Stage 3: Intermediate
├─ 1000-2000 words
├─ Complex sentences, conditionals
├─ Minimal romanization
└─ Goal: Discuss complex topics

Stage 4: Upper-Intermediate
├─ 2000-3000 words
├─ Idioms, cultural references
├─ No romanization
└─ Goal: Understand nuanced conversations

Stage 5: Advanced
├─ 3000-5000 words
├─ Literature, specialized topics
├─ Full target language
└─ Goal: Near-native fluency

Stage 6: Mastery
├─ 5000+ words
├─ Business, technical fields
├─ Professional content
└─ Goal: Professional proficiency

Stage 7: Native-Like
├─ 10000+ words
├─ Slang, regional dialects
├─ Native speaker content
└─ Goal: Indistinguishable from native
```

## 🎓 Example Lesson: "Ordering Food at a Restaurant" (Spanish, Beginner)

### Step 1: Introduction
"Today you'll learn how to order food at a restaurant in Spanish. This is one of the most useful skills for travelers!"

### Step 2: Core Content
"To order food, you say: 'Quisiera...' (I would like...)"

### Step 3: Examples
1. "Quisiera un café, por favor" (I would like a coffee, please)
2. "¿Qué recomiendas?" (What do you recommend?)
3. "La cuenta, por favor" (The bill, please)
4. "Está delicioso" (It's delicious)
5. "No como carne" (I don't eat meat)

### Step 4: Mini Practice
- Listen and repeat: "Quisiera un café"
- Fill in the blank: "Quisiera ___ agua, por favor"
- Speak: "Order a coffee and water"

### Step 5: Mastery Check
- Question 1: How do you say "I would like a coffee"?
- Question 2: What does "por favor" mean?
- Question 3: Record yourself saying "The bill, please"
- Result: 3/3 Correct! 🎉 +25 XP

## 🚀 Getting Started

### For Beginners
1. Start with **Vocabulary** module
2. Learn 100 most common words
3. Practice with **Pronunciation** module
4. Move to **Speaking** module
5. Progress through stages

### For Intermediate Learners
1. Start with **Intermediate** stage
2. Focus on **Grammar** and **Sentence Structure**
3. Practice with **Listening** and **Reading**
4. Add **Idioms & Expressions**
5. Progress to **Advanced** stage

### For Advanced Learners
1. Start with **Advanced** stage
2. Focus on **Cultural Context**
3. Practice with **Conversation**
4. Read authentic materials
5. Aim for **Mastery** stage
