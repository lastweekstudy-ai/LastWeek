## Creating Your First Session

### What is a Session?

A session is a focused study period for a specific subject or topic. All your resources, notes, and progress are organized within sessions.

### Creating a Session

**Method 1: From Dashboard**
1. Click "New Session" button
2. Enter session title (e.g., "Biology Chapter 5")
3. Select study mode
4. Choose subject
5. Click "Create"

**Method 2: Quick Create**
1. Press `Ctrl/Cmd + T`
2. Fill in session details
3. Press Enter

### Session Types

**Study Session**
- For general learning
- Supports all study modes
- Flexible duration
- Best for: Regular studying

**Exam Session**
- Focused exam preparation
- Specific exam date
- Topic-based organization
- Best for: Exam prep

**Quick Session**
- Short focused study
- 25-minute default
- Single topic
- Best for: Quick reviews

### Organizing Sessions

**Naming Convention**:
- Subject - Topic - Date
- Example: "Physics - Mechanics - Week 3"

**Best Practices**:
- One session per topic
- Clear, descriptive names
- Include date for reference
- Archive old sessions

## Uploading Resources

### Supported File Types

| Type | Formats | Max Size |
|------|---------|----------|
| PDF | .pdf | 100MB |
| Audio | .mp3, .wav, .m4a, .ogg, .webm | 25MB |
| Images | .jpg, .png, .svg | 50MB |
| HTML | .html | 10MB |

### Uploading PDFs

**Step 1: Open Resource Panel**
1. Click "📚 Study Resources" button
2. Click "📄 Files" tab
3. Click "Upload" or drag-and-drop

**Step 2: Select File**
1. Choose PDF from computer
2. Wait for upload to complete
3. PDF appears in resource list

**Step 3: View PDF**
1. Click "View" button
2. PDF opens in viewer
3. Start studying!

**PDF Features**:
- Highlight text (5 colors)
- Add notes to pages
- Bookmark important pages
- Search within PDF
- Adjust zoom level
- Track reading progress

### Recording Audio Lectures

**Step 1: Open Audio Processor**
1. Click "🎙️ Audio" button
2. Choose "🎤 Record Live" tab
3. Click "Start Recording"

**Step 2: Record**
1. Speak clearly into microphone
2. Watch recording timer
3. Click "Stop Recording" when done

**Step 3: Process**
1. Review recording
2. Click "✨ Process Audio"
3. Wait for transcription and processing
4. Lecture appears in resources

**Step 4: Study**
1. Click "Study" button
2. Play audio and take notes
3. Highlight important parts
4. Ask AI questions

### Uploading Audio Files

**Step 1: Open Audio Processor**
1. Click "🎙️ Audio" button
2. Choose "📁 Upload Audio" tab

**Step 2: Upload**
1. Click to select file or drag-and-drop
2. Choose audio file
3. Wait for upload

**Step 3: Process**
1. Click "✨ Process Audio"
2. Wait for transcription
3. Wait for note generation
4. Lecture ready to study

## Study Modes Explained

### Mode 1: Mental Model

**Purpose**: Build deep understanding

**How to Use**:
1. Create session in "Mental Model" mode
2. Upload study material
3. AI breaks down concepts
4. Review concept maps
5. Ask clarifying questions
6. Build your understanding

**Best For**:
- Learning new subjects
- Understanding complex topics
- Building foundations
- Conceptual learning

**Example Workflow**:
```
Upload Physics PDF
→ AI extracts concepts
→ Creates concept map
→ You explore relationships
→ Ask "How does force relate to acceleration?"
→ AI explains with examples
→ You build mental model
```

### Mode 2: Active Recall

**Purpose**: Test and strengthen memory

**How to Use**:
1. Create session in "Active Recall" mode
2. Upload study material
3. AI generates questions
4. Answer questions without looking
5. Get immediate feedback
6. Review weak areas

**Best For**:
- Exam preparation
- Testing knowledge
- Identifying gaps
- Retention practice

**Example Workflow**:
```
Upload History notes
→ AI generates questions
→ "What year did X happen?"
→ You answer from memory
→ Get feedback
→ Review if incorrect
→ Move to next question
```

### Mode 3: Spaced Repetition

**Purpose**: Optimize long-term retention

**How to Use**:
1. Create session in "Spaced Repetition" mode
2. Upload material or create flashcards
3. Study flashcards daily
4. Rate your confidence
5. AI schedules reviews
6. Review at optimal intervals

**Best For**:
- Vocabulary learning
- Fact memorization
- Long-term retention
- Language learning

**Example Workflow**:
```
Create flashcards
→ Study today (all cards)
→ Rate confidence (1-3)
→ Easy cards: review in 3 days
→ Hard cards: review tomorrow
→ Continue daily
→ Retention improves over time
```

### Mode 4: Exam Prep

**Purpose**: Focused exam preparation

**How to Use**:
1. Create exam plan with date
2. Add exam topics
3. AI generates study schedule
4. Follow daily recommendations
5. Take mock exams
6. Track progress

**Best For**:
- Exam preparation
- Time management
- Structured learning
- Performance tracking

**Example Workflow**:
```
Create exam plan (30 days until exam)
→ Add 5 topics
→ AI creates schedule
→ Study 2 hours daily
→ Take weekly mock exams
→ Review weak areas
→ Exam day arrives
```

### Mode 5: Focus Breakdown

**Purpose**: Deep dive into specific topics

**How to Use**:
1. Create session in "Focus Breakdown" mode
2. Select specific topic
3. AI extracts all related content
4. Study comprehensive breakdown
5. Generate practice problems
6. Master the topic

**Best For**:
- Difficult topics
- Advanced learning
- Mastery-level study
- Problem-solving practice

**Example Workflow**:
```
Focus on "Calculus - Derivatives"
→ AI extracts all related content
→ Provides detailed explanation
→ Shows worked examples
→ Generates practice problems
→ You solve problems
→ Get detailed feedback
```

## Using Study Tools

### Highlighting & Notes

**Highlighting Text**:
1. Select text in PDF or transcript
2. Choose color from palette
3. Text is highlighted
4. Highlight saved automatically

**Color Meanings** (suggested):
- 🟨 Yellow: Important concepts
- 🟩 Green: Key definitions
- 🟦 Blue: Examples
- 🟥 Pink: Questions/unclear
- 🟧 Orange: Formulas/equations

**Adding Notes**:
1. Click "✏️" button in toolbar
2. Type your note
3. Click "Save Note"
4. Note appears in notes tab

**Viewing Highlights**:
1. Click "🖍️ Highlights" tab
2. See all highlighted text
3. Click to jump to location
4. Ask AI about highlight

### Flashcards

**Creating Flashcards**:
1. Click "Flashcards" button
2. Click "Create New"
3. Enter front (question)
4. Enter back (answer)
5. Click "Save"

**Studying Flashcards**:
1. Click "Study" button
2. Read front of card
3. Try to recall answer
4. Click to reveal back
5. Rate your confidence (1-3)
6. Move to next card

**Spaced Repetition**:
- Easy (3): Review in 3 days
- Medium (2): Review tomorrow
- Hard (1): Review today
- AI schedules automatically

### Quizzes

**Taking a Quiz**:
1. Click "Quiz me" button
2. Read question carefully
3. Select answer or type response
4. Click "Submit"
5. Get immediate feedback
6. See explanation
7. Move to next question

**Quiz Types**:
- Multiple choice
- Short answer
- Fill in the blank
- True/false
- Matching

**Performance Tracking**:
- Score displayed
- Correct/incorrect shown
- Time per question tracked
- Weak areas identified

### Pomodoro Timer

**Starting Timer**:
1. Click "⏱️ Timer" button
2. Default: 25 min work, 5 min break
3. Click "Start"
4. Focus on studying
5. Timer alerts when done

**Customizing Timer**:
1. Click settings icon
2. Adjust work duration
3. Adjust break duration
4. Set number of sessions
5. Save preferences

**Using Breaks**:
- Step away from desk
- Stretch and move
- Hydrate
- Rest eyes
- Return refreshed

## Sharing & Collaboration

### Making Resources Public

**Step 1: Open Resource**
1. Click resource in library
2. View resource details

**Step 2: Share**
1. Click "🔒 Share" button
2. Confirm sharing
3. Button changes to "🌐 Shared"
4. Resource now searchable

**Step 3: Others Can Find It**
1. They search in library
2. Your resource appears
3. They click "Add"
4. Resource added to their session

### Importing Shared Resources

**Step 1: Search Library**
1. Click "🔍 Library" button
2. Enter search term
3. Browse results

**Step 2: Preview**
1. Click resource to preview
2. See title and description
3. View sample content

**Step 3: Import**
1. Click "+ Add" button
2. Resource added to session
3. Appears in your resources
4. Your copy is private

**Step 4: Study**
1. Click "View" or "Study"
2. Study the imported resource
3. Add your own notes
4. Your notes stay private

### Privacy & Control

**What Gets Shared**:
- ✅ Processed content (text, notes, transcript)
- ✅ Diagrams and visualizations
- ✅ Study materials
- ❌ Your personal highlights
- ❌ Your personal notes
- ❌ Your bookmarks

**Controlling Sharing**:
1. Click "🌐 Shared" button
2. Resource becomes private
3. Button changes to "🔒 Share"
4. No longer searchable
5. Others can't import

## Tips & Tricks

### Study Efficiency

1. **Use All Modes**: Combine modes for better learning
2. **Active Engagement**: Don't just read, interact
3. **Regular Review**: Study consistently, not cramming
4. **Spaced Repetition**: Review at optimal intervals
5. **Mix Resources**: Use PDFs, audio, and notes together

### Time Management

1. **Use Pomodoro**: 25-minute focused sessions
2. **Schedule Sessions**: Plan study time
3. **Track Time**: Monitor study duration
4. **Take Breaks**: Rest between sessions
5. **Avoid Multitasking**: Focus on one topic

### Effective Note-Taking

1. **Be Selective**: Highlight key points only
2. **Use Your Words**: Paraphrase, don't copy
3. **Add Examples**: Include relevant examples
4. **Ask Questions**: Note unclear concepts
5. **Review Notes**: Regularly review and refine

### Exam Preparation

1. **Start Early**: Begin 4-6 weeks before
2. **Use Exam Mode**: Follow AI schedule
3. **Take Mock Exams**: Practice under conditions
4. **Review Mistakes**: Learn from errors
5. **Stay Consistent**: Study daily

### Collaboration Tips

1. **Share Quality Resources**: Help others learn
2. **Import Diverse Materials**: Learn from others
3. **Combine Perspectives**: Different explanations help
4. **Build Community**: Contribute to shared learning
5. **Give Feedback**: Help improve resources

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + T` | New session |
| `Ctrl/Cmd + K` | Search |
| `Ctrl/Cmd + /` | Show shortcuts |
| `Space` | Play/pause audio |
| `←/→` | Skip audio (10s) |
| `H` | Highlight mode |
| `N` | Add note |
| `Ctrl/Cmd + S` | Save |

### Troubleshooting

**Problem**: Can't upload PDF
- **Solution**: Check file size (<100MB) and format

**Problem**: Audio won't play
- **Solution**: Check browser compatibility and audio format

**Problem**: Flashcards not saving
- **Solution**: Check internet connection and try again

**Problem**: Quiz not loading
- **Solution**: Refresh page and try again
