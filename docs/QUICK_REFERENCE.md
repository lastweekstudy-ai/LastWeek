# LastWeek Quick Reference Guide

Fast lookup for common tasks and information.

## 🚀 Quick Start

```bash
# Install
npm install

# Setup .env file
cp .env.example .env

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📚 Study Modes at a Glance

| Mode | Purpose | Best For | Tools |
