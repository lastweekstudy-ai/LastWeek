## Study Modes

### 1. Mental Model Mode
**Purpose**: Build deep conceptual understanding of topics

**Features**:
- Structured breakdown of concepts
- Visual diagrams and explanations
- Hierarchical topic organization
- Concept relationship mapping
- Interactive examples

**How It Works**:
1. Upload study material (PDF, audio, or text)
2. AI breaks down content into core concepts
3. Relationships between concepts are visualized
4. Chat interface for clarification
5. Generate concept maps and diagrams

**Best For**: Learning new subjects, understanding complex topics

---

### 2. Active Recall Mode
**Purpose**: Test memory and strengthen retrieval pathways

**Features**:
- Auto-generated quizzes from content
- Flashcard system with spaced repetition
- Multiple choice questions
- Short answer questions
- Performance tracking

**How It Works**:
1. Material is processed into questions
2. Questions presented in random order
3. User answers and gets immediate feedback
4. Difficulty adjusts based on performance
5. Weak areas are prioritized

**Best For**: Exam preparation, retention testing

---

### 3. Spaced Repetition Mode
**Purpose**: Optimize long-term retention through strategic review

**Features**:
- Intelligent scheduling algorithm
- Difficulty-based intervals
- Progress visualization
- Retention statistics
- Customizable review schedules

**How It Works**:
1. Flashcards created from study material
2. Cards scheduled based on difficulty
3. Easy cards reviewed less frequently
4. Hard cards reviewed more often
5. Intervals increase as mastery improves

**Best For**: Long-term learning, vocabulary, facts

---

### 4. Exam Prep Mode
**Purpose**: Focused preparation for specific exams

**Features**:
- Exam timeline tracking
- Topic prioritization
- Study schedule generation
- Mock exams
- Performance analytics

**How It Works**:
1. Create exam plan with date and topics
2. AI generates study schedule
3. Daily study recommendations
4. Progress toward exam tracked
5. Mock exams simulate real conditions

**Best For**: Exam preparation, time management

---

### 5. Focus Breakdown Mode
**Purpose**: Deep dive into specific topics

**Features**:
- Topic-specific content extraction
- Detailed explanations
- Related concepts highlighted
- Practice problems
- Expert-level insights

**How It Works**:
1. Select specific topic to focus on
2. AI extracts all related content
3. Provides comprehensive breakdown
4. Generates practice problems
5. Offers advanced explanations

**Best For**: Mastering difficult topics, advanced learning

## Limitations & Known Issues

1. **PDF Processing**: Very large PDFs (>100MB) may take longer
2. **Audio**: Maximum file size 25MB
3. **Offline**: Limited offline support (cached content only)
4. **Concurrent Sessions**: One active session per user
5. **Storage**: Subject to Appwrite storage limits
