# Study Modes - Quick Reference Guide

## When to Use Each Mode

### 🧠 Mental Model - "I want to UNDERSTAND"
**Use when:**
- Learning a new concept for the first time
- Need intuitive understanding, not just facts
- Want to know HOW and WHY things work
- Prefer analogies and real-world examples
- Building foundational knowledge

**You'll get:**
- Analogies that make concepts click
- Deep explanations of mechanisms
- Connections between related concepts
- Visual concept maps
- "Aha!" moment focus

**Example**: "Think of neurons like electrical wires in your house..."

---

### 🎯 Active Recall - "I want to TEST myself"
**Use when:**
- Preparing for exams/quizzes
- Need to identify knowledge gaps
- Want rigorous practice with feedback
- Already learned basics, need to cement knowledge
- Prefer learn-by-testing approach

**You'll get:**
- Questions BEFORE explanations
- Strict grading out of 10
- Immediate detailed feedback
- Coverage of ALL core concepts
- Re-testing until mastery

**Example**: "Grade: 7/10. You explained X correctly, but missed Y and Z..."

---

### 🔍 Focus Breakdown - "I'm OVERWHELMED"
**Use when:**
- Topic feels too big or complex
- Getting lost in walls of text
- Need clear structure and organization
- Want to tackle one piece at a time
- Easily overwhelmed by information

**You'll get:**
- Complete topic map showing full scope
- Bite-sized chunks (200-400 words each)
- Clear progress tracking
- Sequential building
- Anti-overwhelm approach

**Example**: "📍 FOCUS: Chunk 1 of 4 — Light Reactions... ✓ Completed 1/4"

---

### 🎓 Collaborative Scholar - "I want to learn from the MASTERS"
**Use when:**
- Want historical perspective
- Learn better through storytelling
- Interested in how concepts were discovered
- Appreciate personality in teaching
- Want debate and discussion

**You'll get:**
- First-person roleplay as Einstein, Feynman, Curie, etc.
- Personal anecdotes from their research
- Historical context and discoveries
- Their actual opinions and communication style
- Socratic dialog and debate

**Example (Einstein)**: "When I was at the patent office, I had this thought experiment..."

---

### 🎨 Creative Synthesis - "I want to CREATE something"
**Use when:**
- Learn best by doing/making
- Want hands-on learning
- Need study materials (mind maps, flashcards)
- Prefer active over passive learning
- Want to teach others

**You'll get:**
- Collaborative creation of artifacts
- Choice of formats (mind map, story, project, etc.)
- Iterative building and refinement
- Complete concept coverage validation
- Tangible outputs you can keep

**Example**: "Let's create a mind map together! I'll start the structure, you fill in details..."

---

## Quick Decision Tree

```
Start here: What do you need?

├─ "I don't understand this concept at all"
│  └─ Use: 🧠 Mental Model (analogies + mechanisms)
│
├─ "I need to test if I really know this"
│  └─ Use: 🎯 Active Recall (quiz + feedback)
│
├─ "This topic is too overwhelming"
│  └─ Use: 🔍 Focus Breakdown (map + chunks)
│
├─ "I want to learn from a historical figure"
│  └─ Use: 🎓 Collaborative Scholar (roleplay)
│
└─ "I want to make something to learn"
   └─ Use: 🎨 Creative Synthesis (projects)
```

## Combining Modes (Workflow Examples)

### For Exam Prep:
1. 🧠 Mental Model → Understand concepts deeply
2. 🎯 Active Recall → Test yourself repeatedly
3. 🎨 Creative Synthesis → Create study materials

### For Complex Topics:
1. 🔍 Focus Breakdown → Break into chunks
2. 🧠 Mental Model → Understand each chunk deeply
3. 🎯 Active Recall → Test on each chunk

### For Deep Learning:
1. 🧠 Mental Model → Build intuition
2. 🎓 Collaborative Scholar → Get historical context
3. 🎨 Creative Synthesis → Apply by creating

## Tips for Each Mode

### 🧠 Mental Model
- Ask "Why does this work?" to trigger deeper explanations
- Request "Show me the connections" for concept maps
- Say "Give me another analogy" if first one doesn't click

### 🎯 Active Recall
- Be honest in answers - strict grading helps you improve
- Ask "What concepts haven't you tested yet?"
- Say "Test me again on my weak areas"

### 🔍 Focus Breakdown
- Look at the complete map first - don't skip it
- Take breaks between chunks
- Ask "Break this chunk smaller" if still overwhelmed

### 🎓 Collaborative Scholar
- Engage in debate: "I disagree because..."
- Ask about their personal research process
- Request their opinion on modern developments

### 🎨 Creative Synthesis
- Choose the format that excites you most
- Iterate: "Can we add [X] to this?"
- Keep what you create for later review

## Mode Selection Cheat Sheet

**I need to...**

- **Understand** → 🧠 Mental Model
- **Memorize** → 🎯 Active Recall + 🎨 Creative Synthesis (flashcards)
- **Simplify** → 🔍 Focus Breakdown
- **Get inspired** → 🎓 Collaborative Scholar
- **Remember** → 🎨 Creative Synthesis (mnemonics)
- **Practice** → 🎯 Active Recall
- **Organize** → 🔍 Focus Breakdown + 🎨 Creative Synthesis (mind maps)
- **Explore** → 🧠 Mental Model + 🎓 Collaborative Scholar

---

**Pro Tip**: Don't stick to one mode! Switch modes as your needs change during learning. Start with one, switch to another when it fits better.
