# Language Learning Platform - Complete Setup Guide

## Overview
The Language Learning Platform has been integrated into LastWeek. It uses scientifically proven language acquisition methods including:
- Krashen's Input Hypothesis
- Spaced Repetition (SRS)
- Comprehensible Input (i+1)
- Retrieval Practice Theory

### 1.2 Collection: `lang_users` (User Profiles)

**Purpose**: Stores each user's language learning profile

**Attributes**:
| Attribute | Type | Size | Required | Default | Description |
|-----------|------|------|----------|---------|-------------|
| userId | string | 255 | Yes | - | Reference to main user |
| primaryLanguage | string | 10 | Yes | - | ISO code (en, zh, es, etc.) |
| targetLanguage | string | 10 | Yes | - | ISO code (en, zh, es, etc.) |
| learningRatio | integer | - | Yes | 70 | Learning:Practice ratio (10-90) |
| totalXP | integer | - | No | 0 | Total XP earned |
| currentStage | string | 50 | No | 'beginner' | Current learning stage |
| streakDays | integer | - | No | 0 | Consecutive days studied |
| lastActiveDate | datetime | - | No | - | Last activity timestamp |
| createdAt | datetime | - | No | - | Account creation date |

**Indexes**:
| Key | Type | Attributes | Unique | Purpose |
|-----|------|------------|--------|---------|
| userId_idx | key | [userId] | Yes | Fast lookup by user ID (unique constraint) |
| primaryLanguage_idx | key | [primaryLanguage] | No | Filter users by primary language |
| targetLanguage_idx | key | [targetLanguage] | No | Filter users by target language |

**Full Index Creation Commands** (Appwrite Console):
| Index Key | Type | Attributes | Order | Unique |
|-----------|------|------------|-------|--------|
| userId_idx | key | userId | ASC | Yes |
| primaryLanguage_idx | key | primaryLanguage | ASC | No |
| targetLanguage_idx | key | targetLanguage | ASC | No |

**In Appwrite Console - Create Index Dialog**:
- Index Key: `userId_idx`
- Type: `key`
- Select Attribute: `userId`
- Order: `ASC`
- Unique: `checked` (true)

Repeat similarly for other indexes.

**Permissions** (Appwrite Console - Permissions Tab):
```
Role: Member (any authenticated user)
  - create: Yes (allow all authenticated users to create their profile)
  - read: userId = $id (only read own document)
  - update: userId = $id (only update own document)
  - delete: No

Role: Admin (your team/admin account)
  - create: Yes
  - read: Yes
  - update: Yes
  - delete: Yes
```

**Exact Permission Strings** (for API/CLI):
```
permission:create("member:any")
permission:read("member:any")
permission:update("member:$id")  
permission:delete("admin:any")  // Optional: allow admin to delete
```

```env
VITE_LANG_ROADMAPS_COLLECTION_ID=your_lang_roadmaps_collection_id
```

## PART 3: Update languageLearning.js

You need to update `src/appwrite/languageLearning.js` to use the environment variables:

```javascript
const DB_ID = import.meta.env.VITE_APPWRITE_DATABASE_ID;

export const COLLECTIONS = {
  USERS: import.meta.env.VITE_LANG_USERS_COLLECTION_ID,
  ROADMAPS: import.meta.env.VITE_LANG_ROADMAPS_COLLECTION_ID,
  LESSONS: import.meta.env.VITE_LANG_LESSONS_COLLECTION_ID,
  LESSON_ATTEMPTS: import.meta.env.VITE_LANG_LESSON_ATTEMPTS_COLLECTION_ID,
  PRACTICE_SESSIONS: import.meta.env.VITE_LANG_PRACTICE_SESSIONS_COLLECTION_ID,
  FLASHCARD_REVIEWS: import.meta.env.VITE_LANG_FLASHCARD_REVIEWS_COLLECTION_ID,
```
